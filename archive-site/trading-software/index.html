Trading software

Published May 2, 2015

Trader needs 2 types of software

1. Data, charting and analysis

A trader needs to know the prices. Those prices come from the exchange where they are traded through brokers and their software applications or specialized webpages. Forex is a little different as there is no central exchange.  Traders need also chart and analyze the prices in some kind of charting software. Data feeds (prices, charts) in some software applications are delayed (10-20min) and in other are real time. Real time data are the best. Here are posibilities of software applications:

a/ Brokers offer free, demo or premium trading software applications to individual clients. Applications contain wide variety of trade, research, analysis functions and features like in-built technical indicators, charts, fundamental analysis numbers, integrated applications for trade automations, news, and alert features.

b/ MetaTrader 4 (also 5), also known as MT4 (MT5), is an electronic trading platform. It was developed by MetaQuotes Software. The software is licensed to brokers who provide the software to their clients. The software consists of both a client and server component. The server component is run by the broker and the client software is provided to the broker’s customers, who use it to see live streaming prices and charts, to make complet technical analysis (the best solution for chart analysis) , to place orders, and to manage their accounts.

c/ Currently, there are many webpages like finila.com, tradingview.com etc where real time data, charting and analysis are possible without instalation of software application. Everything is direct on web.

2. Trade Execution

Once traders have their data and can see and analyze it on a chart, they will at some point want to place a trade. To do so, they need to use some kind of trade execution software application or web trading platform. Some traders use for data, charting, analysis and for trade execution software from one broker. Other traders use different software applications for execution and other for data, charting and analysis.

Some software examples:

Metaquotes software downloadable – downloadable MT4 for PC, iPad, IPhone, Android
Also every great broker has the page with the possibility to download MT4. Good demo is FxPro.com
Metaquotes software web – new MT4 web platform, trading directly from browser (see notes)
finila.com – realtime charts, data, analysis (trade execution is through a broker)
