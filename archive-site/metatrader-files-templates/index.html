How to install custom indicators and templates to MetaTrader 4

You have to have installed MT4 (MT5) software.
0. Create new account in MT4 (File > Open an account > add new broker – e.g. FxPro.com-Demo01 > Scan > Next > New demo account – write down the name and password)
1. Download and copy the MT4 custom indicator file or template file on your computer.
2.Open the indicators, templates folder

example of file location

C:\Users\username\AppData\Roaming\MetaQuotes\Terminal\846C681ABC6A1994D56FF979E83B7F69\MQL4\Indicators
C:\Users\username\AppData\Roaming\MetaQuotes\Terminal\846C681ABC6A1994D56FF979E83B7F69\templates

3. Paste the files and the template
4. Restart MT4
5. Open MT4
6. On the navigator, find custom indicators.
7a. If you want to install every indicator separately, then double click the indicator in Navigator box and the indicator properties window will appear. Allow DLL imports.
or 7b. If you want to install all indicators through template, click on charts button, then template and load template (for example our finilacom_template.tpl)
